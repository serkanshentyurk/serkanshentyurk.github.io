Bank Marketing — Imbalanced Classification & Calibration

Predictive modelling on the UCI Bank Marketing dataset; 41,188 observations with ~11% positive class.

Pythonscikit-learnXGBoostDocker
  • Compared logistic regression and XGBoost using stratified cross-validation, selecting models on PR-AUC for the imbalanced target.
  • Calibrated predicted probabilities and set the decision threshold from a fixed call budget rather than 0.5, converting model scores into an expected subscription-capacity forecast.
  • Containerised the analysis with Docker for a reproducible modelling and evaluation pipeline.
github.com/serkanshentyurk/bank-marketing

Eel-Fisher Survey — Statistical Testing & Predictive Modelling

Commissioned statistical analysis for a conservation organisation; n = 51 across two independent questionnaires.

Pythonscikit-learnstatsmodels
  • Harmonised two questionnaires into a 24-field typed dataset and performed type-aware two-sample tests with multiple-comparison correction, identifying eight fields with significant between-group differences.
  • Built regularised logistic-regression models with leakage-safe preprocessing and evaluated limitations caused by small n, near-complete separation, and single-split evaluation.
github.com/serkanshentyurk/eel-fisher-survey

Behavioural Modelling in Mice — State-Space Models & SBI

PhD research: modelling trial-by-trial learning and decision-making in a two-alternative auditory task.

PythonssmsbiSLURM
  • Replaced a data-hungry grid-search estimator with engineered summary statistics and simulation-based inference (sbi), reducing the data required per estimate to a single session (~300 trials) and extending the method to learners where the original approach was unreliable.
  • Developed behav_utils, a reusable Python package for behavioural-data analysis, and built a reproducible HPC pipeline using SLURM array jobs (396-test suite).
  • Applied state-space models to identify recurring learning stages, then used a disentangled RNN to infer latent decision variables and test model-derived hypotheses.
